# 📖 About the Project

SAHA ASSOCIATES is a premium civil engineering consultancy website developed to establish a strong online presence for the company. The website highlights the firm's expertise, completed works, engineering services, careers, and contact information while maintaining a clean, modern, and professional design.

The application follows a scalable full-stack architecture with a React frontend and a Node.js backend connected to a PostgreSQL database.

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/saha-associates.git
```

---

## 2️⃣ Backend Setup

```bash
cd backend

npm install

cp .env.example .env
```

Configure your `.env`

```env
PORT=5000

DATABASE_URL=

JWT_SECRET=

JWT_EXPIRES_IN=

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=

SMTP_HOST=

SMTP_PORT=

SMTP_USER=

SMTP_PASS=

CONTACT_RECEIVER_EMAIL=

FRONTEND_URL=http://localhost:5173
```

Run Prisma

```bash
npx prisma migrate dev

npx prisma generate
```

Start Backend

```bash
npm run dev
```

Backend runs on

```
http://localhost:5000
```

---

## 3️⃣ Frontend Setup

```bash
cd frontend

npm install

cp .env.example .env
```

Inside `.env`

```env
VITE_API_URL=http://localhost:5000
```

Start Frontend

```bash
npm run dev
```

Frontend runs on

```
http://localhost:5173
```
